# BVC website redesign (design preview)

Static preview of a proposed redesign for the Burnaby Velodrome Club website. About 28 pages on the current site collapse to 8.

- `index.html`: home
- `member-hub.html`: Uplifter vs Spond, getting set up
- `programs.html`: Learn to Ride, Coached Workouts, Learn to Race, Youth + Juniors
- `racing.html`: Friday Night Racing, Bare Bones, BVC Mania, track records, results
- `about.html`: story, the track, team, partners, get involved, contact
- `rider-guide.html`: first visit, track rules, safety, out-of-town riders, bookings + rentals, FAQ, policies

Not the live site. Photo, map and partner-logo slots are placeholders. Live site: https://burnabyvelodrome.ca
